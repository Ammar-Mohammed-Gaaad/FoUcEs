# دليل المساعد الذكي "فكرني" (AI Copilot Guide)

## 1. المحرك البرمجي (The Engine)
- **Model**: Llama 3.3 (70B Versatile) عبر Groq API.
- **Speed**: استجابة في أقل من 500ms.

## 2. الأوامر الصوتية (Voice Commands)
- يستخدم المساعد `Web Speech API`.
- **السرعة (Rate)**: 1.0 (طبيعي).
- **النبرة (Pitch)**: 1.0 (واضح).

## 3. منطق الـ Prompts
المساعد مبرمج ليفهم سياق المهام من قاعدة البيانات ويستجيب بلقب "يا هندسة" لتشجيع المستخدم.
